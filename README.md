## Publish on GitHub

1. Create a new public repository named `ronak-mistry.github.io`.
2. Upload all files and folders from this repository.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. Your site will normally be available at `https://ronak-mistry.github.io/`.

## Important confidentiality note

Do not upload proprietary employer/customer drawings, models, BOMs, project numbers, dimensions, screenshots, or other confidential information. Use recreated or sanitized portfolio examples instead.
